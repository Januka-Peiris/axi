# Contributing to AXI

Thank you for your interest in contributing to AXI! We welcome contributions from the community to help make AXI the standard open-source semantic layer.

## Getting Started

1.  **Fork the repository** on GitHub.
2.  **Clone your fork** locally.
3.  **Install dependencies**:
    ```bash
    ./scripts/dev.sh
    ```

## Development Workflow

1.  Create a new branch for your feature or fix: `git checkout -b features/my-new-feature`.
2.  Write code and add tests.
3.  Run tests locally: `pytest`.
4.  Commit your changes with clear messages.
5.  Push to your fork and submit a **Pull Request**.

## Code Style

-   **Python**: We use `ruff` (or `black`/`flake8`) for formatting and linting.
-   **Frontend**: We use `prettier` and `eslint`.

## Reporting Issues

If you find a bug or have a feature request, please open an issue in the repository. Provide as much detail as possible.

## Code of Conduct

Please adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.
