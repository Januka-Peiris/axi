# Introduction to AXI

**AXI** is a semantic layer for the modern data stack. It abstracts your physical data warehouse into business-friendly concepts: **Metrics**, **Dimensions**, and **Relationships**.

## Key Concepts

- **Entities**: The nouns of your business (e.g., `Customer`, `Order`).
- **Metrics**: The calculations (e.g., `Revenue`, `Active Users`).
- **Dimensions**: The context (e.g., `Region`, `Date`).
